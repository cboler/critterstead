# Gemini repository entrypoint

Critterstead's shared project knowledge lives under `docs/`. This is a thin
navigation adapter, not a second game specification or a copy of `AGENTS.md`.

- Start with [README.md](README.md) for setup and controls.
- For gameplay and narrative, use [GAME-DESIGN.md](docs/GAME-DESIGN.md).
- For state, simulation, persistence, or rendering, use [ARCHITECTURE.md](docs/ARCHITECTURE.md).
- For engineering procedures and checks, use [DEVELOPMENT.md](docs/DEVELOPMENT.md).
- For sequence and rationale, use [ROADMAP.md](docs/ROADMAP.md) and relevant entries
  in [DECISIONS.md](docs/DECISIONS.md).
- For substantial work, find the active plan through the
  [execution-plan index](docs/exec-plans/README.md). Its acceptance criteria and
  next action define the current slice.

Read only the material relevant to the task; these links are not a request to
import every document into persistent context. The former `INSTRUCTIONS.md` and
`docs/ASTRA-HANDOFF.md` are compatibility pointers.

Preserve the shared engineering invariants, finish the requested milestone through
appropriate verification and repair, and record stable commits, evidence, and the
next exact action in its plan. Do not advance into later milestones unless the
request authorizes that scope. Keep project facts and decisions in their shared
documents, not in model-specific instructions or chat-only handoffs.
